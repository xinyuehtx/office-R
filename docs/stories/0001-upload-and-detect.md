# Story-0001: 上传并识别 Office 文件

- **状态**:已完成
- **关联**:RFC-0001、Spec-0001

## 用户故事

作为 **office-R 的使用者**,
我希望 **在文档/表格/演示任一页面上传对应的 office 文件**,
以便 **应用能识别文件类型并展示其信息(为后续渲染做准备)**。

## 验收场景(Given / When / Then)

### 场景 1:上传 Word 文档

- **Given** 我在「文档 · Word」页面
- **When** 我通过上传入口选择一个 `.docx` 文件
- **Then** 页面显示识别格式为「Word 文档」、文件大小与占位说明

### 场景 2:切换页面各自上传

- **Given** 我在应用首页
- **When** 我切换到「表格」或「演示」标签
- **Then** 每个页面都有独立的上传入口,可分别上传 `.xlsx` / `.pptx`

### 场景 3:上传无法识别的文件

- **Given** 我在任一页面
- **When** 我上传一个非 office 文件
- **Then** 页面提示「无法识别的文件格式」,不崩溃

### 场景 4:解析出错

- **Given** 内核在处理中抛出异常
- **When** 我上传文件
- **Then** 页面以错误样式展示失败原因
