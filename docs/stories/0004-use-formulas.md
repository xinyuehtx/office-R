# Story-0004: 在表格里用公式计算

- **关联**:RFC-0004、Spec-0004
- **状态**:已实现

## 用户故事

> 作为一个上传了 CSV 的用户,我希望在单元格里写 `=SUM(A1:A10)` 这样的公式,
> 表格能像 Excel 一样算出结果,这样我不用把数据导回 Excel 就能做基本计算。

## 验收场景(Given/When/Then)

### 场景 1:基本算术与引用
- **Given** 一张含数字的表格,`A1=1`、`A2=2`、`A3=3`
- **When** 某单元格写 `=SUM(A1:A3)*2`
- **Then** 显示 `12`

### 场景 2:条件与文本
- **Given** `B2=55`
- **When** 写 `=IF(B2>=60,"及格","不及格")`
- **Then** 显示 `不及格`

### 场景 3:错误优雅呈现
- **Given** 任意表格
- **When** 写 `=1/0` 或 `=FOO()`
- **Then** 分别显示 `#DIV/0!` 与 `#NAME?`,页面不崩溃

### 场景 4:公式栏
- **Given** 一个公式单元格显示计算值
- **When** 选中它
- **Then** 公式栏显示原始公式文本(如 `=SUM(A1:A3)`),单元格显示计算值

### 场景 5:循环引用不卡死
- **Given** `A1=B1`、`B1=A1`
- **When** 求值
- **Then** 两格显示循环错误(`#REF!`),页面不卡死
