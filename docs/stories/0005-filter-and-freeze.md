# Story-0005: 过滤与冻结行列

- **关联**:RFC-0005、Spec-0005
- **状态**:过滤 已实现;冻结 计划中

## 用户故事

> 作为查大表的用户,我希望能**按列筛选**(只看满足条件的行)并**冻结表头/首列**,
> 这样在几十万行里也能快速找到并对齐我关心的数据。

## 验收场景(Given/When/Then)

### 场景 1:数值筛选(已实现)
- **Given** 一张有「单价」列的表
- **When** 选中该列,选「数值 > 3」并应用
- **Then** 只显示单价>3 的行(表头保留),状态栏行数相应减少

### 场景 2:文本 / 值集 / 空白筛选(已实现)
- **When** 选「文本 包含 北京」/「值集 勾选若干」/「空白 只看非空白」
- **Then** 命中行按条件显示;多列条件按 AND 叠加

### 场景 3:原始行号(已实现)
- **Given** 过滤后行不连续
- **Then** 行头仍显示**原始行号**(像 Excel),不是 1..N 重排

### 场景 4:清除过滤(已实现)
- **When** 点某列标签「✕」或「全部清除」
- **Then** 该列 / 全部过滤取消,恢复相应行

### 场景 5:冻结行列(计划中)
- **When** 点「冻结首行」/「冻结首列」
- **Then** 横竖滚动时表头行 / 首列保持可见;「取消冻结」还原
