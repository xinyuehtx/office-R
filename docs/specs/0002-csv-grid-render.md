# Spec-0002:CSV 表格视图渲染

- 关联:[RFC-0003](../rfcs/0003-csv-canvas-grid.md)、[Story-0002](../stories/0002-view-csv-sheet.md)
- 状态:已实现

## 范围

**做**:CSV 文本的只读表格视图渲染(解析 → 列切分 → canvas 绘制 → 滚动/缩放/选中)。

**不做**(本期):公式求值、数字/日期格式化、图表、单元格编辑与写回、多工作表、
列宽拖拽、排序筛选、区域选择与复制。

## 输入

| 项 | 约定 |
| --- | --- |
| 文件类型 | `.csv` / `.tsv` / `.txt`(按内容判断,不信任扩展名) |
| 编码 | UTF-8(含 BOM)、UTF-16LE/BE(带 BOM)、GBK/GB18030/Big5/Shift_JIS 等由探测决定 |
| 分隔符 | 自动嗅探 `,` `\t` `;` `|`;也可显式指定 |
| 体积上限 | 256 MiB |
| 行数上限 | 2,000,000 |
| 列数上限 | 16,384(与 Excel 一致) |

## 解析行为(office-core)

| 情形 | 期望行为 |
| --- | --- |
| 常规 CSV | 按分隔符切分为行 × 列 |
| `"..."` 包裹字段 | 引号内的分隔符与换行都是普通字符 |
| `""` 转义 | 在引号内表示一个字面 `"` |
| 字段内嵌换行 | 不拆行;渲染时换行符显示为空格(单行单元格) |
| CRLF / LF 混用 | 行数与内容均正确,不残留 `\r` |
| UTF-8 BOM | 剥离,不出现在首个单元格 |
| 末尾空行 | 不产生数据行 |
| 中间完全空白行 | **跳过**,不占行号(与 `csv` crate / pandas / csvkit 一致) |
| 末尾仅含一个空字段的行(如 `""`) | 视为噪声,裁掉 |
| 各行列数不一致 | 列数取各行最大值,**短行右侧补空单元格** |
| 空字段 | 保留为空单元格 |
| 超长单元格文本 | 完整解析,不截断;仅显示时裁剪 |
| 非 UTF-8 编码 | 探测后解码;有字符解不出时标记 `lossy` 并在界面提示 |
| 单列文件(无分隔符) | 退回默认逗号,按 1 列渲染 |

## 错误行为

| 情形 | 错误 | 面向用户的表现 |
| --- | --- | --- |
| 0 字节 / 只有空白 | `Empty` | 「文件内容为空,没有可显示的数据」 |
| 超过体积上限 | `TooLarge` | 报出实际大小与上限,建议拆分 |
| 二进制内容(含 NUL 或大量不可打印字符) | `NotText` | 「这看起来不是文本文件…」 |
| 解码不出任何文本 | `Undecodable` | 报出探测到的编码 |
| CSV 结构损坏 | `Malformed` | **带出错行号** |

所有失败都必须:不 panic、不白屏、保留文件名、给出可操作提示、允许重新选择文件重试。
超过行/列上限时**截断而非失败**,并在界面标注「已达上限,超出部分未显示」。

## 渲染要求

| 项 | 要求 |
| --- | --- |
| 绘制方式 | 表格主体**全部**由 canvas 绘制;DOM 只承载容器、交互层、文件输入、状态栏与无障碍元素 |
| 图层 | 单元格 / 行列头 / 覆盖层拆成三张堆叠的 canvas,叠加由浏览器合成器(GPU)完成;各自独立脏标记,谁变了只画谁 |
| 画布尺寸 | 由容器驱动(`ResizeObserver`),随窗口自适应 |
| HiDPI | 后备像素与显示尺寸**同源换算**,保证「后备像素 = 显示尺寸 × dpr」严格成立 —— 否则浏览器会重采样整块位图导致发虚。非整数 dpr(浏览器缩放、125%/150% 显示缩放)下同样成立;切换显示器(dpr 变化)后重新出图 |
| 行列头 | 列头 `A/B/C…`、行头 `1/2/3…`,滚动时**固定**不动 |
| 首行 | 浅色底,便于识别表头行 |
| 文本 | 左对齐、垂直居中、统一内边距;超出列宽**裁剪并以省略号结尾** |
| 网格线 | 1 物理像素,压在像素中心不发虚 |
| 选中/悬停 | 选中单元格描边 + 底色,并高亮其所在行列表头;悬停单元格淡色底 |
| 滚动条 | canvas 自绘(纵/横),长度反映可见比例,可拖拽 |
| 空表 | 画占位提示,不崩溃 |

## 交互要求

| 通道 | 行为 |
| --- | --- |
| 滚轮 / 触控板 | 纵横双向滚动(透传 `deltaX`/`deltaY`,处理 `deltaMode`) |
| **Shift + 滚轮** | **横向滚动** —— 鼠标用户唯一的横滚方式,浏览器不会自动转换;平台已给出 `deltaX` 时不重复转换 |
| Ctrl(⌘)+ 滚轮 | 缩放,**以指针为锚点**:指针下的单元格保持不动 |
| 拖拽 | 左键按住拖动平移视图(移动小于阈值则视为点击选中) |
| 滚动条拖拽 | 拖动滑块跳转 |
| 点击 | 选中单元格;点行头选中该行首格,点列头选中该列首格 |
| 方向键 | 移动选区,并自动滚动进视野 |
| PageUp / PageDown | 上下翻一屏 |
| Home / End | 行首 / 行尾 |
| Ctrl+Home / Ctrl+End | 表格首格 / 末格 |
| Ctrl +/- / 0 | 放大 / 缩小 / 复位 |
| 缩放范围 | 50% – 300% |

缩放后坐标换算与命中判定必须仍然准确。

## 性能要求

| 指标 | 要求 |
| --- | --- |
| 视口虚拟化 | 每帧只绘制可见区域(+ 少量 overscan),与总行数无关 |
| 解析线程 | 在 Web Worker 中完成,主线程不被长时间阻塞 |
| 首屏 | 40 MB / 50 万行级别的文件,秒级可见 |
| 滚动 | 60 FPS,无明显掉帧 |
| 跨边界拷贝 | 解析结果以可 transfer 的缓冲交回主线程;表格常驻 WASM 内存,不整体转成 JS 字符串 |
| 帧内合并 | 单帧内的多次状态变更只触发一次重绘 |
| 增量重绘 | hover / 选区变化**不得**触碰单元格层 |
| GPU 平移 | 单元格层是超出视口一圈的瓦片;滚动未超出余量时**主线程零绘制**,只改 CSS transform;滚出余量才重锚,并用位图平移复用重叠区 |
| 取数范围 | 按**瓦片**而非可见区域取数,否则瓦片边缘会画成空白,一平移就穿帮 |

## 可观测性要求

- 前端与 WASM 两侧日志**格式一致**,同一次打开共用一个 `traceId`,可串联;
- 分级 `debug/info/warn/error/off`,默认不刷屏(开发 `info`,生产 `warn`);
  可通过 `?logLevel=debug` 或 `localStorage.officeR.logLevel` 调整;
- 关键阶段均有记录:文件打开、解析成功/失败、截断、有损解码、首帧;
- 日志带上下文与耗时:文件大小、行列数、编码、分隔符、解析耗时、首帧耗时;
- **绝不打印单元格内容**,避免泄露用户数据。

## 验收标准

1. 上述解析行为逐条正确,且有 Rust 单测覆盖;
2. 上述错误行为逐条正确,失败后可重新选择文件恢复;
3. 表格主体由 canvas 绘制,页面中不存在 DOM 表格;
4. 滚动、缩放、键盘、拖拽、滚动条均可用,缩放后命中判定准确;
5. 40 MB / 50 万行文件首屏秒级、滚动 60 FPS、解析期间主线程不冻结,并有实测数据留档;
6. 几何计算为纯函数且有单测;渲染管线的分层与增量行为有单测断言;
7. `cargo fmt/clippy/test` 与 `pnpm typecheck/test/build` 全绿。
